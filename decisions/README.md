# Decisions

Core and important business decisions live here.

## Naming

`NNNN-short-kebab-title.md`

Example: `0001-use-numbered-decisions.md`

Use the next unused 4-digit number. Never reuse or renumber.

Do not rewrite an old decision. If it changes, add a new numbered file that supersedes it.

Keep each file short: context, decision, why, and consequences.
