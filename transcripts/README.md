# Transcripts

Store internal call transcripts and voice notes here so your agents can search past discussions and extract takeaways.

## Folder layout

- `team-calls/` - Regular syncs and reviews.
- `strategy/` - Big planning and direction calls.
- `voice-notes/` - Raw voice memos and transcripts from walks or brainstorms.

Keep one `learnings.md` file inside each folder. After adding new transcripts, ask your agent to append the top 3 to 5 dated takeaways to `learnings.md`.

## Privacy rule

Only save meetings where every participant is on your internal team allowlist (or explicitly agreed to be recorded and stored). Exclude external calls with clients, candidates, or partners unless you have permission.
